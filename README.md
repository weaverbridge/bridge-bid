# Bridge Bid

Phone app for building bridge detailing bids and Weaver Bridge Corporation detailing quotations.

Live at **https://weaverbridge.github.io/bridge-bid/** — open in Safari on iPhone, then Share › Add to Home Screen.

- Customer list, email addresses and settings are not stored here. They live on the phone and in the
  owner's OneDrive (Apps › Bridge Bid › settings.json).
- `config.js` holds the Microsoft 365 app registration IDs (not secrets).
- `vendor/` holds jsPDF 2.5.1 and MSAL Browser 3.28.1.
